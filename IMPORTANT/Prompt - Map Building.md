# Master Prompt: Map Building

Back to [[Roblox Dev Resources]] | Rules this prompt must follow: [[Build Rules]]

```
Build the map like a professional game environment, not a quick AI blockout.

WORKFLOW:
Study → Blockout → Playtest → Build → Detail → Optimize → Test Again.

First inspect the reference and understand:
scale, layout, architecture, landmarks, elevation, interiors, roads, routes, combat spaces, traversal and sightlines.

Do NOT make:
random box buildings
giant empty areas
useless rooms
repetitive hallways
fake doors everywhere
random props pretending to be detail

Every major area needs a purpose.

Make the map:
Dense • Memorable • Believable • Fun to Explore • Easy to Learn

Add meaningful:
interiors
shortcuts
alternate routes
rooftops
stairs
alleys
vertical paths
hidden areas
landmarks

Build believable architecture with proper entrances, windows, rooms, storage, staff areas and back routes.

Make environments look lived-in with dirt, wear, signs, clutter and environmental storytelling, but do NOT overfill everything.

Test the map through actual gameplay.

Check:
collision, scale, lighting, AI navigation, player movement, performance, clipping, floating props and broken routes.

If the map is boring, change the layout.
If it looks generic, give it identity.
If it is empty, add meaningful density.
If it is cluttered, clean it up.

Make players think:
"Wait… I can actually go there?"

LOW-USAGE MODE: Do not repeatedly scan unchanged files or explain the same plan. Batch related map changes together, test them once, and give one short report afterward.

Build → Test → Fix → Improve → Test Again.
```
