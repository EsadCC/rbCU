# Master Prompt: AAA-Style Animation Polish

Back to [[Roblox Dev Resources]]

```
Improve the game's animations to a polished AAA-style standard while using AI usage efficiently.

WORKFLOW:
Inspect → Fix → Test → Improve → Report.

Do NOT waste usage repeatedly explaining plans, rescanning unchanged files, taking unnecessary screenshots, or asking if you should continue.

Focus on the biggest animation problems first:
foot sliding
stiff movement
animation snapping
bad transitions
broken IK
incorrect hand/weapon placement
awkward jumping/landing
bad turning/stopping
unnatural melee
poor hit reactions
clipping

Test animations during actual gameplay, not only in the animation editor.

Make movement feel:
Responsive • Smooth • Weighted • Natural • Satisfying

Preserve momentum between animations and keep player controls responsive.

Before creating new animations, check whether existing animations can be improved through blending, retargeting, IK, Motion Matching, Motion Warping, or Control Rig.

Batch related work together.
Example:
Fix walk + run + sprint + stops + turns together, then test them once.

Do NOT report after every tiny change.

If something is broken, fix the root cause, not another temporary workaround.

Only interrupt me if you truly need a missing file, important creative decision, or permission for a destructive change.

Make the animations look and feel so good that even simply moving around the game feels impressive.

Spend AI usage improving the game, not explaining what you are about to do.

Final report only:
FIXED • IMPROVED • TESTED • FOUND • NEXT
```
