# Prompt — Map Building (Master)

Back to [[IMPORTANT Index]] | Rules: [[Build Rules]] | Kit: [[1-Stud Kit]]

> [!important] Core instruction
> Build the map like a **professional game environment**, not a quick AI blockout.

## Workflow

**Study → Blockout → Playtest → Build → Detail → Optimize → Test Again**

## 1. Study

First inspect the reference and understand:

- Scale, layout, architecture
- Landmarks, elevation
- Interiors, roads, routes
- Combat spaces, traversal, sightlines

## 2. Do NOT make

- Random box buildings
- Giant empty areas
- Useless rooms
- Repetitive hallways
- Fake doors everywhere
- Random props pretending to be detail

**Every major area needs a purpose.**

## 3. Make the map

Dense • Memorable • Believable • Fun to Explore • Easy to Learn

Add meaningful:

- Interiors
- Shortcuts
- Alternate routes
- Rooftops
- Stairs
- Alleys
- Vertical paths
- Hidden areas
- Landmarks

Build believable architecture with proper entrances, windows, rooms, storage, staff areas and back routes. Make environments look lived-in with dirt, wear, signs, clutter and environmental storytelling — but do **NOT** overfill everything.

## 4. Test through actual gameplay

Check: collision, scale, lighting, AI navigation, player movement, performance, clipping, floating props, broken routes.

## 5. Fix by symptom

| Symptom | Fix |
|---|---|
| Boring | Change the layout |
| Generic | Give it identity |
| Empty | Add meaningful density |
| Cluttered | Clean it up |

The goal: players think *"Wait… I can actually go there?"*

## Low-usage mode

Do **not** repeatedly scan unchanged files or re-explain the same plan. Batch related map changes together, test them once, give one short report afterward.

**Build → Test → Fix → Improve → Test Again.**
