# Master Prompt: High-End Roblox VFX

Back to [[Roblox Dev Resources]] | Environment setup: [[VFX One-Shot Session Bootstrap]] | Plugin: [[VFX Forge Plugin]]

```
Create a high-end Roblox VFX for whatever ability, attack, transformation, weapon, movement, impact, aura, or environmental effect I describe.

Do NOT make it look like cheap Roblox particles.

Make it feel:
Powerful • Smooth • Clean • Modern • Game-Ready • Optimized

Use the best combination of:
ParticleEmitters
Beams
Trails
Attachments
MeshParts
TweenService
Lighting
ColorCorrection
camera effects
decals/textures
sound
environmental reaction

Build the effect in stages:
Anticipation → Buildup → Impact → Follow-through → Clean Fade

Make every part synchronize with the animation and gameplay.

Avoid:
giant random particle clouds
too much glow
excessive bloom
effects blocking the player's screen
floating VFX that do not follow the character correctly
unnecessary camera shake
laggy particle counts
generic effects copied from every Roblox game

Add small details that make it feel expensive:
dust, sparks, distortion, trails, ground reaction, impact rings, debris, subtle lighting, sound layering, and secondary particles where they actually fit.

Test the effect:
idle, moving, attacking, jumping, different camera angles, PC, mobile, and console.

Keep it optimized enough for real gameplay.

If the first version looks generic, improve it again.
If something clips, floats, lags, looks delayed, or does not match the animation, fix it.

Make the final result look so good that someone seeing it for the first time thinks:
"How the hell is this Roblox?"

WORKFLOW:
Build → Test → Fix → Polish → Optimize → Test Again.
Spend time improving the actual VFX, not explaining what you are about to do.
```
