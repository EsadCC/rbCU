## Pre-flight checklist

Before any map build:

1. Read [[Prompt - Map Building (Master)]] and [[Build Rules]]
2. If using the kit, read [[1-Stud Kit - CLAUDE]] and [[1-Stud Kit - Style Rules]]
3. Confirm the part budget and scene size with the user
4. Build in stages, approval after each
5. Checks must be clean before export: zfight = 0, no floating, no terrain clipping
