# 1-stud building: UNITS (SHELVED)

**Decision (user, after Construct stud redo, Mega Construct v1/v2 and Stud Mech):** 1-stud style is a scenery style, not a unit style. Units stay in their current house style. Don't restyle units in stud style.

Why: the environment work succeeded because it sat on approved pieces and a generator; units have neither, and a part kit would only serve one unit. Most units don't need it. The only good stud-unit reference (`uploads/pasted-1791169474357-0.png`) is essentially a castle with mechanical joints: wall-trim crenellations on top and a medieval sword.

**Where stud style CAN touch units:** structures that units carry, built as set pieces with the environment rules, e.g. the War Elephant howdah, wagons, platforms, a tank's deck props. Treat those as props/structures, not as the unit body.

Kept for reference only (not used): `construct-stud.js`, `mega-construct.js`, `mega-construct-v2.js`, `stud-mech.js` and their previews; they're the record of what was tried. Fundamentals that were agreed then (clean, silhouette at gameplay zoom, the unit's own palette, proportions follow the role, rig contract kept) still hold for any unit work in general.
