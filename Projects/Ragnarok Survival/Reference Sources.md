## ARK UI — layout facts (from reference screenshots)

### In-game HUD (bottom-right + bottom-center)
- Survival stat pips stacked bottom-RIGHT: Health (red), Stamina (yellow), Oxygen (blue), Food (orange), Water (cyan), Weight, plus temperature icon.
- Hotbar bottom-CENTER: 10 slots, numbered 1–0, dark translucent tiles.
- Top-left / top-right: buff + status icons.
- Warm/cold warning text flashes top-center (e.g. "You're cold!").

### Inventory / Crafting screen (the big one)
Three-column layout over a hex-grid translucent teal panel:
1. **LEFT — INVENTORY:** search bar, sort buttons, grid of item tiles. Each tile shows icon + name + xQty + weight. Tabs at top for CRAFTING.
2. **CENTER — YOU / stats:** character name, level, day/time/temp/wind readouts, XP bar + "POINTS AVAILABLE", then the stat list (HEALTH, STAMINA, OXYGEN, FOOD, WATER, WEIGHT, MELEE DAMAGE, MOVEMENT SPEED, CRAFTING SPEED, FORTITUDE, TORPIDITY) each with value + a "+" button to spend points.
3. **RIGHT — 3D character preview** on a hex backdrop.

### Character creation / customization screen
- Dark teal hex background.
- LEFT column: MALE/FEMALE toggle, tabs (body/color/preset/random), sliders for HEAD, TORSO, ARMS, LEGS (chest, shoulders, hip, torso width/height/depth, arm length, upper/lower arm, leg length, etc.).
- CENTER: large 3D character preview.
- RIGHT: Spawn Region buttons + Survivor Name field + "CREATE NEW SURVIVOR" button.

### Options / Advanced Settings
- Left nav categories (AUDIO, GRAPHICS, GAMEPLAY, CAMERA).
- Rows of label + slider or checkbox, cyan accents, hex watermark behind.
- APPLY / SAVE buttons top-right.

### Session List (server browser)
- Top: "ARK Official Server Network Status: Healthy (vXXX)".
- Filter row: NAME FILTER, MAP dropdown, GAME MODE, SORT BY.
- Table columns: SESSION | MAP | PLAYERS | PING | DAY | MODE | BUILD.
- Bottom: JOIN LAST PLAYED, JOIN, REFRESH, ADD TO FAVORITES, CANCEL.
- Footer: patch number + total server count.

### Boot / main menu
- Solid dark background (NOT a live 3D scene).
- Large glowing metallic **triangular ARK "A" logo** centered, with:
  - blue triangular jewel at TOP corner
  - red jewel lower-LEFT
  - green jewel lower-RIGHT
  - left branch brown→blue, right branch blue→green
  - etched circuit-like lines + geometric shapes on the face, notches on edges
- Menu buttons BELOW, simple text: JOIN ARK / HOST \ LOCAL / OPTIONS / EXIT.
- Small patch + version text in a corner.
