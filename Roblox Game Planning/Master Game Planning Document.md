# MASTER GAME PLANNING DOCUMENT

An architectural guide for creating a Roblox game with AI.

> [!info]- Original header notes (marked "delete before pasting" in the source)
> Contact @jsmelo on discord for concerns.
> Not a 1:1 Recreation of the TikTok you've seen. This is due to the fact that AI will be helping you write/expand this document as seen fit.
> **YOU MUST HAVE A CLEAR GAME IDEA, REALISTIC GOALS, AND FUNDAMENTALS SET TO USE THIS. NO EXCEPTION. YOU MUST BE VERY SPECIFIC AND DETAILED.**

## Ground rules

- The user must fill this document out manually before major development begins.
- AI may help expand, clarify, organize, or improve information ONLY after the user has established the core ideas.
- AI will use this document to create a proper development roadmap, checklist, system plan, concepts, and implementation order.
- AI MUST continuously refer back to this document and the approved roadmap while developing the game.
- AI MUST NOT silently invent major gameplay mechanics, progression systems, monetization, lore, functionality, or design decisions that contradict or replace what the user has established.
- If important information is missing, unclear, contradictory, or unrealistic, AI must identify it before that area of development begins.
